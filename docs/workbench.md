# 本地工作台

## 启动

在仓库根目录执行：

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-web.txt
python workbench.py
```

打开 http://127.0.0.1:7860。`python workbench.py --port 7862` 可换端口；同一仓库只允许一个工作台服务，换端口前先退出原服务。已有 `.venv` 时只需激活并运行最后两条命令。Windows 可用 `.venv\Scripts\python.exe`。真实出片需要 Python 3.10+、ffmpeg 和 ffprobe（macOS：`brew install ffmpeg`）。不需要 Node 或 pnpm dev。

## 不用 key 演示

1. 保持「离线演示」开启。「一条片段」填提示词、秒数（默认 12）和画幅，可上传图片，再启动。
2. 「整条片」加载示例，选 shot，点击「先演示分镜图」。缺少示例角色图片时会使用占位图。
3. 右侧预览分镜，修改任一张的生成提示词，点击「仅重出这张演示图」。其他图片不变。
4. 点击「继续演示整片」，查看日志、report.md，并在 Plyr 中播放视频；可拖进度、调音量/倍速、全屏。

演示媒体含 DEMO 标记，不联网、不收费，不模拟模型理解新提示词的效果。缺 ffmpeg 时仍能产出计划、图片和报告，日志会说明没有视频。

## 配置真实 key

打开「环境与密钥」，填写 `RUNNINGHUB_API_KEY` 和 `APIMART_API_KEY`，默认勾选保存到本机 `.env`，点击保存；保存后立即用于后续任务，服务重启也会沿用。不勾选则只存当前服务内存。空白 key 保持已有值，不会回显明文。`.env` 已被 git 忽略，权限为 0600，不写入浏览器存储或任务 JSON。也可预先按 `.env.example` 手动配置；已 export 的环境变量在启动时优先于 .env。

工作台固定 `H3_REWRITER=llm`，不探测或运行 Claude。默认 `LLM_BASE_URL=https://api.apimart.ai/v1`、`LLM_MODEL=deepseek-v4-pro`，改写使用 APIMart key；自定义 OpenAI 兼容服务可填写 LLM key / URL / model。高级的 `VISION_API_KEY`、`VISION_BASE_URL`、`H3_GUIDE_FILE` 等仍从 .env / 环境读取，手动修改后重启工作台。页面环境检查不联网鉴权或查余额，无效 key 会在实际任务中明确报错。

## 真实生成与单镜改词

1. 关闭「离线演示」。one 上传 1–9 张参考图（顺序对应参考图片编号），填写提示词、秒数、画幅，可选 seed 和强制字幕检查，直接启动。
2. film 加载/编辑 JSON，上传参考图并绑定角色/总表。手写相对图片路径时，将「JSON 所在目录」填为原 JSON 所在目录；相对目录以仓库根为基准，留空就是仓库根。示例默认 `examples`；上传绑定的绝对路径不受此项影响。
3. 选 `shot`（每镜一图）或 `first`（每段首图），点击「先生成分镜图」。这一步只需 APIMart key，不调用视频或改写 API。`none` 无分镜可编辑，直接走完整出片。
4. 在右侧任一分镜卡片修改「这张图的生成提示词」，点击「仅重出这张图」。这是图像模型提示词，直接交给原 `frames.draw`；不要把它当作视频六段式提示词编辑框。卡片列出的参考图及顺序保持不变。
5. 新图成功后替换该图，其他分镜不会重画；失败时保留旧图，可从任务历史续跑。新提交的 task 单独持久化，续跑查询该 task。改第一张锚图不会自动重画其余图；以后单独重画其他图时使用新锚图。
6. 满意后点击「继续生成整片」。原仓库完成改写、RunningHub 视频、字幕检查、拼接和报告。若是已有成片的改图任务，界面会标明旧视频/报告待更新；shot 只重做所属片段，first 从该段向后重做以延续末帧衔接。

也可跳过审图，直接启动完整出片。实际出现的分镜受原 CLI 每段 9 张参考图预算限制。输出目录留空自动分配 `jobs/demo/<id>` 或 `jobs/web/<id>`；自定义目录必须不存在或为空，输入保存在其 `inputs/` 内。

## 状态、播放与恢复

任务历史刷新后保留，显示实际阶段、已落盘分镜/片段数、最近约 100 KB 日志、报告和产物路径。视频使用本地分发的 [Plyr 3.8.5](vendor-plyr.md)，不依赖运行时 CDN；报告以纯文本展示。云端等待阶段可能长时间没有新日志。

一次运行一个本地任务。失败后可更新 key，再从原任务续跑；续跑使用任务已保存输入，不读取左侧新表单。改整个脚本请新建任务，单镜改图使用右侧卡片。

关闭网页不停止任务；退出服务会中断本地执行，但不保证取消已提交云端任务。服务重启后可续跑查询已记录 task。原 CLI 在远端提交成功、任务号尚未写盘之间仍有重复提交窗口。源参考图被移动后，历史结果仍可查看，但缺图分镜不可重出。

`.workbench/`、默认 `jobs/` 和 `.env` 已忽略；自选其他仓库内输出目录需自行忽略。服务仅监听本机。CLI 安装和命令保持兼容，真实任务调用原 CLI / 包内 API；具体对照见 [CLI 一致性说明](workbench-cli-parity.md)。离线演示与假 API 检查不能证明真实鉴权、余额或模型效果。

# 分镜列表 / 大图切换与分页增强

状态：用户补充的分页增强与大图模式均已实现并完成离线验证，等待本轮界面体验反馈。

## 需求与成功标准

保留现有分镜列表，新增可切换的大图浏览方式。同一时刻只显示一张主分镜图，通过上一张 / 下一张浏览全部分镜；右侧显示该图现有提示词、参考图和操作。

- 两种模式使用同一组分镜数据和编辑草稿。
- 大图、提示词、参考图、重生成按钮始终对应同一分镜。
- 切换视图、上一张 / 下一张、语言切换和后台轮询不丢失未应用的编辑。
- 列表继续每页最多 12 张，大图导航覆盖全部分镜，跨过原分页边界不受影响。
- 保留现有角色引用限制：只选任务最初导入的角色；总表与首镜锚点只读。
- 分镜列表与视频列表均可直接输入页码跳转，并支持首页 / 末页快捷操作；两类列表保持独立页码。

## 已确认的项目结构

- Flask 模板：`workbench/templates/results.html`。
- 分镜渲染、草稿、分页和生成操作：`workbench/static/results.js`。
- 共用参考图编辑器：`workbench/static/frame-references.js`。
- 视频列表和播放器生命周期：`workbench/static/video-segments.js`。
- 样式：`workbench/static/style.css`。
- 界面国际化：`workbench/static/messages/zh-CN.json`、`en.json`。
- 现有 API 已返回所有分镜、提示词和引用信息，无需后端改动或新增依赖。

## 提议的交互

1. 默认列表模式；分镜区顶部增加「列表 / 大图」切换，显示选中状态。
2. 大图模式左侧为自适应尺寸的完整主图，不裁切；右侧直接显示提示词编辑、完整参考图列表、角色选择及单图重生成操作，不要求额外展开。
3. 图片附近放置「上一张 / 第 X 张，共 N 张 / 下一张」；首尾禁用对应按钮，无自动播放、不循环跳转。
   用户追加：大图模式直接按键盘 ← / → 切换，复用上述按钮行为；文本输入、下拉选择、可编辑文本、输入法组字、组合快捷键以及其他 Tab 的方向键操作不触发切图。
4. 列表转大图时，从当前列表页首张开始；若该页包含刚查看的大图则保留该图。大图转列表时，定位至当前分镜所在页。
5. 单张分镜禁用前后导航；没有分镜时保留空态；尚未生成图片的分镜显示等待占位，同时保留对应信息。
6. 窄屏时主图在上、信息在下，避免侧栏挤压图片和编辑区。
7. 本轮不增加全屏、自动轮播、缩略图条、刷新后视图记忆或新的生成入口。
8. 两类列表底部提供「首页 / 上一页 / 当前页与总页数 / 下一页 / 末页」及带标签的页码输入与跳转按钮，支持回车提交；分镜仍每页 12 张，视频仍每页 6 段。
9. 页码必须为 1 至总页数之间的整数。空值、小数、负数、零和越界值用中英文校验提示纠正，不静默修正或跳页。首尾及只有一页时禁用对应快捷按钮。
10. 后台轮询不覆盖正在输入的页码；翻视频页停止并销毁离开页面的播放器，普通轮询保留当前播放器。大图仍使用逐张导航，不混用列表页码。

## 实现边界

在现有结果页内提取共用的单分镜卡片构建函数，两种视图仅改变可见分镜范围、布局及编辑区展开方式。继续使用按 `frame.key` 保存的提示词和参考图草稿，复用已有提交、禁用和轮询逻辑。列表展开状态与大图默认展开相互独立。

模板增加视图切换和大图导航；CSS 只新增相关布局和响应式规则。所有新增可见文案及无障碍标签写入现有中英 JSON。

两类列表复用一个小型分页模板和前端绑定函数，统一输入校验与按钮边界，各自渲染函数继续维护原有页码和卡片生命周期。

工作区已有多项未提交修改，实施时只改动本功能需要的部分，不覆盖既有改动，不提交、推送或重打包 Windows 版本。

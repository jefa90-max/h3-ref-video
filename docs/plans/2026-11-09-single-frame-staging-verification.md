## 已验证

- 调度边界：v2 必填/类型/角色别名/重复、固定布局不可随反打变化；身体与视线可不同；袋口、袋底、结扣与裁切各自保留；起点不提前展示交接结果，文字终点只进入视频。
- 逐镜图片：参考身份不再携带全片旧姿势；真实有序参考编号、审核词过滤和三字段旧缓存兼容。
- 顺序规划：跨视频段、换场返回、未来缓存不污染前镜；Event 证明第 2 镜文字被阻塞时第 1 镜已开画；单镜规划/图片失败不终止其余镜，恢复原 task 或已缓存文字不重新付费；shot/first/none 与九图限额保持。
- 缓存与视频：手改文字、参考重排或文件版本变化使失配调度退出下游；preflight 与 stage_prompts 共用判定；完成片段、task、unknown 冻结旧词；换分镜→重新确认→pipeline 捕获的 RH graph 仍采用手改视频词。
- 视频编辑：source/H3 查看、明确切换与配对；原词复用 H3，改 source 先存新 H3 再提交，直接 H3 本地六段/编号检查；版本冲突、旧 API、终态失败无视频、未知接单/未决 task 保护均覆盖。
- 发布事务：clip/tail/zh/h3/active/applied 六步注入 OSError，提交前 GET 与 Range 读取旧视频和旧词，恢复时 rewrite/upload/submit 为零；旧 v 不返回新版字节；仅目标段和尾帧替换，成片等待人工拼接。
- HTTP 集成：查看→改第 2 段→轮询失败保留旧片→续查原任务→发布→待拼接→人工拼接；其它段字节保持。网络与媒体生成边界均为 mock；占位字节只证明本地事务，未冒充可播放模型视频。
- UI：中英两套 DOM 回归覆盖实际 POST payload、每格式草稿、展开/分页/Tab/语言、独立基线与显式 rebase、匹配 revision 才清草稿、播放器和焦点/选择区/IME 保留、运行/unknown 锁、首次失败修复。新文案全部来自 JSON，Node 回归进入 CI。

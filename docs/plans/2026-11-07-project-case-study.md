# 视频自动生成工作台：项目案例介绍

## 目标

制作一份简洁的中文案例 PDF，以 3 页、每页 2 张项目截图说明主要功能，让未接触项目的读者理解从剧本到视频的工作流程。

## 内容组织

1. 从脚本创建任务：单片段 / 整条片、参考图绑定、分镜模式与自动改写。
2. 先审图再出片：分镜列表、大图浏览、提示词编辑与角色参考图管理。
3. 从片段到交付：片段预览与局部重生成、整片拼接下载、任务续跑和报告。

以实际代码和现有页面为证据。截图优先复用现有任务；如来自离线演示，标明素材性质，不冒充真实模型效果。字幕检查当前暂停，不作为已启用能力宣传。不引用随时间变化的价格，不把历史测评当成性能承诺。

## 执行与验收

- 使用本项目 `.venv` 启动工作台，仅监听本机，保留原任务与配置；不调用 Claude 或付费生成接口。
- 使用 Tabbit 获取真实页面截图；截图完成后停止本次服务并核对监听状态。
- PDF 使用嵌入中文字体，每页两张清晰截图和对应功能说明；输出到 `output/pdf/`。
- 检查页数、中文可提取、图片数量和尺寸；逐页渲染目检，确认没有文字溢出或模糊。
- 交付后由用户对案例内容和版式提出修改意见。

# Wave 2 提示词对照试验

用同一组输入、模型和生成配置比较每项提示词改动。评分员先看匿名画面和剧本要求，提交视觉票后再核对任务状态与费用。这份方案可先离线运行。实际模型报价、素材和付费额度确认后才能冻结付费试跑。

## 指标与决策

- 每项改动在对应的历史痛点和常规对照中取得净胜，且叙事动作、角色状态及常规对照均无退化。
- 没有新增内容审核拒绝。画面缺失、上游拒绝和异常失败单独记录。
- 单镜或单段提示词字符数与估算费用增幅分别不超过 15%。合并候选时另做一轮同配置回归，检查累计规则字符增幅不超过 20%，规则没有冲突。
- 过线则交由用户选择是否合入。出现审核或常规对照退化则搁置相关改动。结果不确定则保留原规则，补充对应类别的真实样本后再评。

## 对照组

| 组别 | 唯一变更 | 固定条件 |
|---|---|---|
| 3A | 生图转译词表 | 原始画面描述与参考图 |
| 3B | 构图提示中的动作示例 | 同模型和拍摄要求。只把构图结果交给生图 |
| 3C-neg | 生图尾句里的文字、标志等描述 | 其他尾句，含布光 |
| 3C-light | 生图尾句的布光 | 其余相同 |
| 3D | H3 改写的视觉否定引导 | 同一冻结首帧与视频种子。另测仅替换示例，保留两条正常否定对照 |
| 4 | H3 改写的面部与肢体表演引导 | 同一冻结首帧与视频种子。另测仅替换示例，含克制表演对照 |
| 2A | 成套的单镜状态覆盖与连续性规则 | 相同跨镜身份锁定和参考资料，核对入镜前变化及镜内变化两种情况 |

生图组使用 15–20 个镜头。构图和英文改写分别用已配置的 DeepSeek 或 Gemini 与 Claude 跑同模型内配对。两侧视频种子相同。图片接口若不提供种子，记录这一限制。只有在获得可核验的真实素材后才能用画面判断改动。

## 盲评、试跑与费用

- 每组保留基线与单项候选，评审板按预设种子随机左右，用相同尺寸和播放控制。评审人给出左优、平局或右优和失败原因。已封存的视觉票可导出。
- 对照包含正常否定和克制表演，检验改动是否误删剧情信息或放大不需要的情绪。没有独立留出集之前，结果仅用于这批样本的选择。
- 用固定种子分层选出每臂最多三条试跑样本，其中优先覆盖真实痛点和常规对照。试跑结果单独记录，待核对任务账单、素材与模型可用性后才批准扩大范围。
- 费用按实际请求分步预约，已知金额单独记录。供应商未返回实际费用时保留估算占用，不能记为零。RunningHub 会员币估算与 ComfyUI 外部 GPU 费用分开核对。
- 预约超过用户给出的总额、供应商接单状态未知、素材哈希不符或恢复指纹变化时停止。原任务 ID 已记录的步骤只恢复查询。付费前冻结样本、规则、模型设置、报价和评分标准。

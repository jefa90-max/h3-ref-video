# 独立结果页与分镜确认

用户要求：结果独立页面，适合 100+ 分镜；先生成分镜，确认全部后才生成视频。

1. 创建页只负责配置、导入/绑定与启动；任务进入独立 /jobs/<id> 结果页，刷新/直接打开能恢复。历史任务提供结果页链接。
2. film 首次提交固定运行 frames 阶段，不再提供直接整片生成的旁路；one 保持直接片段生成。shot/first 分镜完成后停在审核；none 没有图，需要明确确认脚本计划。
3. 结果页分步骤展示分镜生成、审核、视频生成及完成。分镜分页（每页 12 张），提示词按需展开，保留单图重出。用户已明确选择统一确认：浏览完只点一次“确认全部并生成视频”，不需要逐张打勾；无图任务统一确认脚本计划。
4. 后端持久化当前整批图片版本的确认记录；改图后需要重新确认；continue API 在一次请求中校验当前版本、确认并启动，不能仅靠按钮禁用。任务恢复同样不能越过审核。
5. 验证 100+ 分镜分页/计数/刷新，未确认 API 拦截，单图变更失效，任务继续/失败恢复与 CLI 兼容。原模型调用与生成逻辑保持原实现。

关键边界：实际分镜数量遵循原 CLI 的参考图预算；不自动改切段或凭空补图。图片完成与用户确认是两个不同状态。只检查已生成且可读取的图片版本；新的生成结果必须重新审核。

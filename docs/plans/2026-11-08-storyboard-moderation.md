# 分镜提示词与内容审核失败处理

## 目标

自动拼装分镜图提示词时，将常见敏感词和夸张表达转为中性、非血腥的可见画面描述，包括用户明确要求避开的“死”字。只处理图片提示词，不改原始剧本、台词或视频提示词；不增加付费改写调用。手动编辑后的提示词按用户输入提交。

APIMart 提交或轮询返回明确内容审核拒绝时，保存该分镜的失败状态、任务号和原始错误，不在同一次运行或之后的普通续跑中重新提交。未明确终止的云端任务仍沿用原任务号查询。其它失败保留原有策略。

## 实施与验收

1. 在现有 frames 模块规范自动提示词，覆盖画风、场景、动作和人物描述，保留构图与参考图编号。
2. 区分内容审核拒绝与一般生成错误，贯通提交、轮询、批量分镜和单图重生成的持久化记录。
3. 失败卡片显示审核拒绝原因，允许在任务空闲时编辑并手动重新生成，包括首次失败、尚无图片的分镜。依赖的首镜锚图缺失时仍阻止提交。
4. 用离线回归复现旧行为，再验证审核拒绝只提交一次、续跑零提交、改词后只更新目标图，成功后清除失败状态。运行完整 Python / JS 测试和编译检查。

## 边界

- 词语规范不能代替供应商审核，也不能保证所有提示词通过；参考图同样可能被拒绝。
- 不自动重写审核拒绝后的提示词，不自动启动手动生成，不启动或重启服务，不调用 Claude。
- Context7 额度耗尽；已查阅 APIMart 官方异步图片任务说明：https://apimart.ai/model/gpt-image-2-6 。沿用现有模型和请求参数，不升级模型。

## 验证结果

已完成自动提示词处理、审核失败持久化、失败卡片手动改词恢复，以及首图修复后继续剩余分镜。用户补充所有含“死”的表达均需消除，已覆盖“死命、死盯、死寂、死撑”等用例。状态未确定的云端任务禁止被新编辑覆盖，审核失败的旧预览也不能用于视频确认。

# Windows 一键部署和本机成果目录

日期：2026-11-02

## 用户目标

在 Windows 10/11 Intel/AMD 64 位电脑解压即可双击安装启动。首次允许联网。用户能通过系统目录选择器选择成果根目录，该设置保存到本机，下次启动默认恢复。每个新任务在根目录内按本机时间创建子目录；已有任务续跑不重新分配目录。

## 实现范围

- 一个 Windows CMD 入口调用 PowerShell 5.1 脚本，下载并验证完整 Python 运行时与 FFmpeg，创建项目虚拟环境安装依赖，校验运行条件并启动浏览器和本地工作台。后续启动复用本机依赖，不修改系统 PATH，不要求预装 Python。
- 目录偏好保存在被忽略的 `.workbench/preferences.json`。页面显示当前根目录，选择系统文件夹后自动保存；取消保持原值。不将此偏好或 API key 打进发布包。
- Windows 使用 PowerShell STA 系统文件夹对话框；macOS 使用系统文件夹选择器。服务仅监听本机，选择接口沿用同源保护。原生对话框运行在独立进程，避免 Flask 线程直接调用 GUI 框架。
- 新建任务使用 `YYYY-MM-DD_HH-mm-ss` 子目录，冲突加 `-001`、`-002`，通过原子 mkdir 防止覆盖。目录不可用、无权限或指向内部存储时明确失败，不悄悄改到别处。
- 新工作台请求使用 `output_root`；持久化任务里的 `output_dir` 仍是最终目录。保留旧调用显式 output_dir 的行为，保证旧任务恢复及 CLI 兼容。
- 页面布局只修改输出目录区域；所有新增文字使用现有中英文 JSON。
- 打包使用显式文件清单，只包含应用、工作流、示例、必要静态资源、依赖声明、脚本和文档；排除开发环境、真实任务、个人配置、密钥和图片素材。

## 验证标准

1. 选择后保存、取消不变，重新创建服务对象仍恢复相同目录；中文和空格路径正确。
2. 同秒多个任务生成不同目录，已有文件不覆盖；错误路径和内部存储不可使用。
3. 续跑原任务不创建新目录，改默认目录不影响旧任务。
4. 全量 unittest、Python 编译、JS 语法和模板检查通过。
5. PowerShell 语法解析通过，压缩包可解压启动导入，必需资源齐全、敏感文件不存在，生成 SHA256。
6. 当前 macOS 环境不宣称 Windows 真机实测通过；交付包含 Windows 首次启动和原生目录选择的用户验收步骤。

# 分镜角色参考图编辑

## 已确认范围

- 在结果页分镜提示词下展示本次生成会使用的全部参考图，按实际发送顺序编号。
- 仅当前分镜的角色图可增删；场景／道具总表与首张分镜锚点只读。
- 增加时只能选择第一步已导入本任务的角色参考图；结果页不提供上传入口。点击单张重新生成时提交提示词及角色图列表，保存到该分镜记录，不修改全片角色定义或其它分镜。
- 显式空角色列表表示不使用角色图，固定参考图继续保留。增删后提醒用户检查提示词内的图片编号，不自动改写用户提示词。
- 旧任务兼容原始角色绑定；展示的是当前文件及下次生成输入，不宣称是历史图片的参考图快照。

## 实现与验证

1. 后端分镜描述提供带类型的参考图和安全预览地址；任务级返回最初导入的角色清单。仅接受该清单内的角色图修改，固定图由服务器重建。
2. 重生成请求保存本次完整引用顺序，成功后发布角色绑定，失败续跑沿用同一输入和任务编号。
3. 前端独立参考图组件，按镜头保存草稿；分页和轮询不丢编辑。选择器展示原始角色缩略图及名称，已经选中的角色不重复添加。
4. 离线验证：删光角色仍保留固定图、选择未自动命中镜头的原始角色图并到达模型边界、持久化/失败续跑、缺失角色移除、非本任务角色图拒绝、其它分镜不变。
5. Python 虚拟环境编译与全套测试、JS 语法和界面检查。临时验证代码删除，来源限制回归永久保留并单独提交；不启动或重启用户服务，不调用付费生成接口。

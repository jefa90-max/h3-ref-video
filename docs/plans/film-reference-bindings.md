# film 导入后的参考图绑定

目标：用户只提供故事 JSON，再按清单上传图片，不编辑磁盘路径；离线与真实模式共用绑定流程。

1. 解析原 JSON 中 cast 角色与 board 场景/道具总表，生成有名称、描述、必填状态的参考位。用户已确认沿用现有格式：逐角色图 + 一张场景/道具总表，不从自由文字拆出额外图片位。
2. 用逐项上传卡片替换单一下拉绑定器和 JSON 所在目录。显示待上传/已绑定、预览、替换与移除；上传映射与原 JSON 分离，提交时由服务端生成符合 CLI 的绝对图片路径。
3. 导入新 JSON 清空旧绑定；编辑角色后防止图片错误绑定到另一角色。缺图真实模式在启动前列出缺项；演示明确说明占位图，仅在选用演示占位时允许缺图。
4. 验证原 CLI 不变；覆盖缺少 picture 的 JSON、旧路径被上传覆盖、多个角色、board、非法/缺失上传、重新导入清空、两种运行模式。补充浏览器点击与文档。

边界：自由文字 setting 本身没有可靠的逐物件分隔规则，不猜测图片位；核心 film/rewrite/frames 不重写。所有界面和服务提示均使用中英文 JSON。

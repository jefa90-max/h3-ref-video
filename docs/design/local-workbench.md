# H3 本地工作台

目标：单人、本机浏览器完成环境检查、one / film 输入、启动、日志与产物查看。保留现有 CLI 行为。

方案：Flask + 原生 HTML/CSS/JS；不用前端构建器、数据库、桌面打包。真实任务用当前虚拟环境的 Python 子进程执行 h3ref.py，环境强制 H3_REWRITER=llm；不探测或调用 Claude。进程日志由后台线程读取。一次运行一个任务，失败可续跑；不提供可能误导为云端取消的停止按钮。

默认离线演示：不联网、不收费，复用 film.load / plan / refs / compile_prompt 校验与生成计划，Pillow 生成明确标为 DEMO 的分镜占位图，有 ffmpeg 时输出占位视频；没有 ffmpeg 时也成功输出报告并明确说明无视频。演示绝不写真实 state.json 或冒充 AI 成片。

输入：one 提示词、按顺序上传的 1–9 张图、5–15 整数秒、画幅、输出目录；film JSON 编辑/导入/恢复示例，shot/first/none，上传图映射到 cast.picture / board。JSON 内相对图路径按界面填写的 JSON 所在目录解析；浏览器不能自动获知导入文件原目录，也可上传重新绑定图片。示例演示允许用占位图替换缺失参考，真实任务必须存在图片。

配置：读取已有 .env / 进程环境，界面可将设置保存到被忽略的本机 .env（0600、原子替换、保留其它行），也可只保留服务内存；key 仅返回是否存在，不回传值。提供 RunningHub/APIMart/LLM key、LLM URL / model。真实任务按需求检查 key、ffmpeg/ffprobe。配置检查不是远程鉴权或余额检查。

边界：仅监听 127.0.0.1，限制 Host / 同源写请求，上传限制与图片内容校验。独立的新任务输出目录避免覆盖；只从已登记任务目录提供产物，阻止目录穿越和符号链接越界。报告和日志以纯文本展示，不渲染不可信 HTML。任务注册信息存于忽略的 .workbench，重启将未完成任务标为 interrupted，可手动续跑；输入与输出保留在各任务目录。

UI：中文为默认，提供英文切换，所有新增界面文字及服务提示来自对应 JSON 字典。左侧流程编辑，右侧持续可见的任务进度/日志/报告/下载；窄屏上下布局。不会伪造远程百分比，展示实际日志和已完成分镜/片段数。

验收：不带 key 点击 one 和 film 三种演示模式成功；真实模式缺 key / 缺图先报错；上传角色后 JSON 路径更新；真实命令构造与现有 CLI 一致；失败/重启可查看任务并续跑；原 14 个离线测试通过；执行 Python 编译检查、JS 语法检查及桌面/窄屏浏览器点击验证。真实付费生成未授权，不执行。

审图增强：先画图直接调用 film.stage_frames；单镜调用 frames.draw 并记录独立 task，下载成功才替换；失败续查新 task。改图后视频标记待更新，继续出片调用原 film.run；与 CLI 共用提取的 invalidate_segments 失效规则，只应用一次。film.load 的 check_images 默认仍开启，仅历史展示关闭源图存在性检查。播放器使用本地 Plyr 3.8.5，图像提示词、视频提示词保持明确区分。详见 docs/workbench-cli-parity.md。
